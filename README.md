# WEB3-TOKEN-AND-ON-CHAIN-ACTIVITY-DASHBOARD

## Project Objectives
• Analyze on-chain transaction trends and activity.
• Measure wallet growth and monthly active wallets.
• Compare buying and selling behavior.
• Evaluate transaction activity across wallet types.
• Identify whale wallets based on holdings.
• Analyze gas fees across transaction types.
• Compare liquidity pool fee performance.
• Track W3X token price movements.
• Build an interactive Excel dashboard for data-driven insights                     


## Questions Asked
What month had the highest transaction volume?
How many monthly active wallets are there?

What percentage of transactions were buys vs sells?
Which wallet type contributes the most transaction volume?
How many wallets can be classified as whales or otherwise
Which transaction type has the highest average gas fee?
Which liquidity pool generates the most fees?
What was the highest and lowest token price?


 ## Key Insights
•	December recorded the highest transaction volume, indicating a significant increase in on-chain activity toward the end of the year. 
•	Buy transactions were higher than sell transactions, accounting for 53.9% of transaction activity compared with 46.1% for sells. 
•	Add Liquidity transactions had the highest average gas fee, making them the most gas-intensive transaction type in the dataset. 
•	Retail wallets contributed the highest transaction volume among all wallet types, showing that retail participants were the most active by transaction value. 
•	W3X/ETH generated the highest liquidity pool fees, outperforming the W3X/USDC, W3X/USDT and W3X/DAI pools. 
•	Wallet activity remained relatively strong throughout the year, although active wallets fluctuated from month to month. 
•	Token prices experienced noticeable variation during the year, reflecting changes in the value of W3X over the period analyzed.
